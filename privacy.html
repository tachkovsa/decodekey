Privacy policy

Last updated: November 2026

What we collect

Nothing. DecodeKey has no accounts, no cookies for tracking, no analytics and no advertising scripts. The tools run entirely in your browser.

Your input

Text you paste into a tool is processed locally by JavaScript. It is not transmitted to the server and is not stored anywhere. Reloading the page clears it.

Server logs

The web server keeps standard access logs (IP address, timestamp, requested URL, user agent) for security and capacity planning. Logs are rotated and are not shared with third parties.
