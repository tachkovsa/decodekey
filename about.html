About DecodeKey

A small toolbox for developers, made by a developer.

DecodeKey is a collection of tiny utilities I kept rewriting in browser consoles: inspect a JWT, decode a Base64 blob, escape markup, format JSON. Instead of pasting sensitive tokens into random websites, I built a set of pages that do the work locally.

How it works

Every tool is plain JavaScript running in your browser. There is no backend, no analytics and no third-party scripts. When you paste a token, it never leaves the page — you can verify that in the network tab of your browser.

What it is not

DecodeKey does not verify signatures and is not a security product. A decoded JWT is not a trusted JWT: always verify signatures on the server with the correct key.
